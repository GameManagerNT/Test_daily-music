# 🎵 每日一推薦 (Daily Music Recommendation)
為個人練習用製作的推薦音樂網站，以手動更新playlist每日推薦一首歌曲於置頂。

## 目前功能如下:

### 自動化與資料處理
* **動態 Day 天數計算**：大標題會根據歌曲總數自動更新天數（例如：`🎵 每日一推薦 DayXX 🎵`）。
* **YouTube 封面自動解析**：自動提取 YouTube 影片 ID 並抓取高畫質（HQ）封面圖片，無需手動填寫圖片連結。
* **今日推薦自動判定**：根據當前日期自動選取當天的推薦歌曲，其餘歌曲自動歸類至歷史清單。

### 歷史清單與搜尋體驗
* **動態搜尋功能**：支援即時關鍵字搜尋（歌名、歌手），搜尋結果為 0 時會顯示「無」提示。
* **分頁瀏覽機制**：歷史歌曲支援自訂分頁（每頁 10 筆），提供上一頁/下一頁按鈕與目前頁碼顯示。

### Canvas 背景動畫效果 
* **不重複洗牌機制 (Deck Shuffling)**：落下的封面採用動態抽牌邏輯，確保畫面上飄落的封面不重複，直到所有歷史歌曲登場後才重新洗牌。
* **互動與視覺優化**：微調半透明度與旋轉角度，並確保背景動畫不干擾點擊操作。

### 效能優化與記憶體管理
* **Debounce (防抖) 搜尋機制**：搜尋框設有 200ms 防抖延遲，避免連續打字觸發頻繁過濾與畫面重繪。
* **動態記憶體分配與管理**:據裝置 CPU 核心數動態配置 Canvas 粒子數量。
建立貼圖池（Texture Pool）控管記憶體上限，自動釋放舊圖片引用（img.src = ""），防止 Memory Leak 與顯存暴增。

### 資訊保護
* **DOM-based XSS 防禦**：資料渲染前經過 escapeHTML() 轉義特殊字元，防止惡意程式碼執行。
* **偽協議與釣魚攻擊防禦**：sanitizeURL() 強制校驗網址，封殺 javascript: 偽協議注入。
外跳連結加上 rel="noopener noreferrer"，防範 Tabnabbing 釣魚攻擊。
* **CSP (Content Security Policy) 安全標頭**：限制外部資源載入來源，硬性攔截未授權的腳本與危險元件。
